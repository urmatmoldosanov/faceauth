# FaceAuth Premium

FaceAuth Premium — легкая PHP-панель для контроля экзаменов: брендированный вход, реестр студентов, которые прошли проверку, и доказательная карточка с фото студента и фото нарушения.

## Что внутри

- Премиальный интерфейс с логотипом, названием продукта и адаптивной версткой.
- Безопасная форма входа администратора с `password_hash` / `password_verify`.
- Два варианта базы данных: SQLite для установки без заморочек или MySQL для production-хостинга.
- Автоматическая установка при первом открытии сайта: приложение проверяет подключение, создает таблицы и демо-записи.
- Демо-записи, чтобы сразу увидеть карточки студентов и доказательную базу.
- Хранение пользовательских файлов в `storage/uploads`.

## Установка как WordPress

1. Загрузите файлы проекта на хостинг с PHP 8.1+. Можно загрузить весь проект целиком; корневые `index.php` и `.htaccess` перенаправят запросы в `public` и закроют служебные папки.
2. Для SQLite включите расширение `pdo_sqlite`; для MySQL включите `pdo_mysql` и заранее создайте пустую базу данных.
3. Если хостинг позволяет, настройте корень сайта на папку `public`. Если не позволяет — оставьте корнем весь проект.
4. Убедитесь, что PHP может писать в папки `config` и `storage`.
5. Откройте домен в браузере.
6. Заполните форму первого запуска: название системы, бренд, логин, пароль и тип базы данных.
7. При выборе MySQL укажите host, port, database, user и password из панели хостинга.
8. После установки приложение создаст `config/config.php`, таблицы и откроет страницу входа.

## Что выбрать: SQLite или MySQL

- **SQLite** — самый простой вариант: не нужен отдельный сервер БД, подходит для демо, пилота и небольшого количества проверок.
- **MySQL** — рекомендуемый вариант для production: привычен для хостингов, проще масштабировать, бэкапить и подключать к другим сервисам.

## Полный комплект файлов

- `index.php` и `.htaccess` в корне — fallback для обычного shared-хостинга, где нельзя выбрать document root.
- `public/` — публичная точка входа и ассеты интерфейса.
- `config/` — пример конфига и закрытие папки от прямого веб-доступа.
- `storage/` — локальная SQLite-база и uploads, закрытые от прямого веб-доступа.
- `database/` — SQL-схемы для ручной установки MySQL/SQLite.
- `scripts/package.sh` — сборка архива проекта для передачи или загрузки на сервер.
- `PROJECT_FILES.md` — короткий чеклист всех файлов цельного проекта.

Собрать архив проекта:

```bash
./scripts/package.sh
```

## Установка на VPS

```bash
php -S 0.0.0.0:8080 -t public
```

Для production используйте Nginx/Apache и направьте document root на `public`. Папки `config` и `storage` не должны быть доступны напрямую из веба.

## Ручная конфигурация

Если нужно подготовить конфиг заранее:

```bash
cp config/config.example.php config/config.php
```

Для MySQL в `config/config.php` замените блок `database`:

```php
'database' => [
    'driver' => 'mysql',
    'host' => '127.0.0.1',
    'port' => '3306',
    'name' => 'faceauth',
    'user' => 'faceauth_user',
    'password' => 'strong-password',
    'charset' => 'utf8mb4',
],
```

Затем замените `admin_password_hash` на хеш своего пароля:

```bash
php -r "echo password_hash('your-strong-password', PASSWORD_DEFAULT), PHP_EOL;"
```

## Структура

- `index.php` — корневой fallback для shared-хостинга.
- `public/index.php` — публичная точка входа, installer, логин, dashboard и schema bootstrap для SQLite/MySQL.
- `public/assets/css/app.css` — премиальная тема интерфейса.
- `public/assets/img/*.svg` — встроенные плейсхолдеры фото студента и нарушения.
- `config/config.example.php` — пример настроек с SQLite и MySQL.
- `database/*.sql` — схемы таблиц для ручного создания.
- `scripts/package.sh` — сборка zip/tar.gz архива проекта.
- `storage` — SQLite база и загруженные доказательства.
