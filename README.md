# FaceAuth Premium

FaceAuth Premium — легкая PHP/SQLite панель для контроля экзаменов: брендированный вход, реестр студентов, которые прошли проверку, и доказательная карточка с фото студента и фото нарушения.

## Что внутри

- Премиальный интерфейс с логотипом, названием продукта и адаптивной версткой.
- Безопасная форма входа администратора с `password_hash` / `password_verify`.
- SQLite база без отдельного сервера БД.
- Автоматическая установка при первом открытии сайта.
- Демо-записи, чтобы сразу увидеть карточки студентов и доказательную базу.
- Хранение пользовательских файлов в `storage/uploads`.

## Установка как WordPress

1. Загрузите файлы проекта на хостинг с PHP 8.1+ и расширением `pdo_sqlite`.
2. Настройте корень сайта на папку `public`.
3. Убедитесь, что PHP может писать в папки `config` и `storage`.
4. Откройте домен в браузере.
5. Заполните форму первого запуска: название системы, бренд, логин и пароль администратора.
6. После установки приложение создаст `config/config.php`, SQLite базу и откроет страницу входа.

## Установка на VPS

```bash
php -S 0.0.0.0:8080 -t public
```

Для production используйте Nginx/Apache и направьте document root на `public`. Папки `config` и `storage` не должны быть доступны напрямую из веба.

## Ручная конфигурация

Если нужно подготовить конфиг заранее:

```bash
cp config/config.example.php config/config.php
```

Затем замените `admin_password_hash` на хеш своего пароля:

```bash
php -r "echo password_hash('your-strong-password', PASSWORD_DEFAULT), PHP_EOL;"
```

## Структура

- `public/index.php` — точка входа, installer, логин, dashboard и SQLite schema.
- `public/assets/css/app.css` — премиальная тема интерфейса.
- `public/assets/img/*.svg` — встроенные плейсхолдеры фото студента и нарушения.
- `config/config.example.php` — пример настроек.
- `storage` — база SQLite и загруженные доказательства.
